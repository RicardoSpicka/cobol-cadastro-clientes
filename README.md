COBOL — Cadastro de Clientes

Aplicação de terminal desenvolvida em COBOL para gerenciamento de cadastros de clientes, utilizando o compilador GnuCOBOL.

Objetivo

Este projeto tem como objetivo praticar a linguagem COBOL, explorar conceitos tradicionais de processamento de dados e demonstrar conhecimentos de programação em um repositório público de portfólio.

O desenvolvimento será incremental, começando pela estrutura básica da aplicação e evoluindo para operações completas de cadastro e armazenamento em arquivos.

Tecnologias

COBOL: linguagem de programação.

GnuCOBOL: compilação e execução local.

Git: controle de versão.

GitHub: hospedagem do código-fonte.

Funcionalidades

Menu principal interativo

Cadastro de clientes

Listagem de clientes

Consulta por código

Alteração de cadastro

Exclusão de cadastro

Persistência dos dados em arquivo

Validação de entradas

Ambiente de desenvolvimento

O projeto utiliza GnuCOBOL e pode ser compilado e executado localmente no Windows, sem necessidade de acesso a um mainframe IBM Z.
